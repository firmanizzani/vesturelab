# VESTURE LAB - Premium Basic T-Shirt E-Commerce

Vesture Lab is a modern web application designed for browsing, selecting, and ordering premium basic T-shirts online.

## Features

**Product Catalog & Variant Selection:** Interactive color swatches, dynamic sizing options (S to XXL), extra pricing calculation, and real-time product image previews.  
**Cart & Order Management:** Slide-in cart drawer with live total calculation, quantity adjustments, and persistent cart state stored in LocalStorage.  
**Checkout & Payment Simulation:** Multi-step checkout flow with customer details, courier selection (JNE, J&T, SiCepat, Gojek), and payment modal with Virtual Account & QRIS simulation.  
**User Authentication & History:** Client-side login/register modal, guest checkout authentication gate, and persistent order history drawer with status tracking.  
**Custom Branding:** Modern minimalist aesthetic with custom color schemes, responsive mobile navigation bar, and optimized touch controls.

## Tech Stack

**Frontend:** HTML5, Vanilla JavaScript (ES6+), Tailwind CSS (CDN)  
**Backend & Storage:** LocalStorage (Cart, Orders, Accounts, Session)  
**Deployment:** GitHub Pages / Vercel (Static Hosting)
